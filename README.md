# Unwip releases

Update packages for **Unwip — Write to finish**. Unwip checks here and installs new versions by itself.
You don't need to download anything from this page to update.

## Download

The friendliest way in: **[unwip.app/get](https://unwip.app/get/)**

**[Download Unwip for Windows](https://github.com/UnwipOfficial/unwip-releases/raw/main/Unwip-Setup.exe)**: run it, and Unwip installs and keeps itself up to date.

Windows may say "Windows protected your PC", because Unwip isn't paid-for signed. Click **More info**, then **Run anyway**.

**Mac:** [Apple chip](https://github.com/UnwipOfficial/unwip-releases/releases/download/mac-app/Unwip-Mac-AppleSilicon.zip) or [Intel](https://github.com/UnwipOfficial/unwip-releases/releases/download/mac-app/Unwip-Mac-Intel.zip). The first time, macOS asks you to allow it: System Settings › Privacy & Security › Open Anyway.

On an iPhone, iPad or any other computer, use Unwip in the browser: **[unwip.app](https://unwip.app)**. On an iPhone or iPad, open it in Safari, tap Share, then **Add to Home Screen**.
