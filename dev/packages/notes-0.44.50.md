- Copy for Royal Road (in the menu beside Copy for Docs, on a chapter's right-click menu, or Ctrl+K). It gets a chapter ready for Royal Road's editor. Each [system message] becomes a box Royal Road keeps (a table), and messages next to each other share one box. Pick Royal Road's own table look (it suits light and dark themes), a blue box, a dark system window or a plain border, and see a preview in light and dark. Italics, bold and scene breaks come across. Footnotes move to the end. Pictures are marked where they go, with a button to save them for uploading (Royal Road doesn't keep pasted pictures).
- Two ways to put it in: Copy, then paste straight into Royal Road's editor; or Copy HTML code, for the editor's source code view. Coloured or centred boxes only survive the HTML code route, and the window tells you which one to use.
- On a phone, Build pieces have a ⋯ button with Copy picture, Save PNG and Add to book. Copy picture and Save PNG couldn't be reached on phones before, and the piece's name now has room next to Record.
- Maps have a Done button, with Copy picture, Save PNG, Add to book and Done in the same order as the other Build editors. On a phone, Done stays in reach while the toolbar scrolls, and the floating ✕ no longer covers the buttons on Build maps.
- On a phone, the "keep your books safe" banner on the main screen wraps properly instead of squeezing the text into a thin column.
- Settings: a row of section names at the top jumps to each section; nothing is hidden. Sections that take effect as you change them (LitRPG, licence, where your books live, extra backup) now say "applies straight away", because Cancel can't undo those. The two font buttons sit together, with a note on where the other font settings are.
- Help has new topics: Build and each of its pieces, Record (proof of writing), LitRPG tools, the LitRPG ledger, word games, Copy for Royal Road, where to find fonts, and how credit works for the game-icons symbols. Some older topics were out of date and are fixed (the side panel has six tabs; phones have Play, Build and Record; where books are kept on a phone).
- Wording: Unwip says "book" everywhere it meant your book ("project" stays only for Scrivener projects). The Record button has one name everywhere. New map in a book explains how it differs from a Build map.
- The theme choice says Match Mac, Match iPhone or Match iPad on those devices, instead of always saying Match Windows.
- On the web and iPhone/iPad, "Open library folder" and "Show in folder" are gone, because there's no folder there to show.
- Fixed: a Word comment containing a double quote (") could be cut short when the file was imported.
- Fixed: typing a quote mark into the Help search box could break the box.
- Smoother typing in long chapters, especially on phones: the word count and side panel badges update a moment after you stop typing, not on every key.
- A tidy-up behind the scenes: unused and repeated styles were removed (letter animations had three copies), with no change to how anything looks.
