- Continuity pass (Revise panel, or Ctrl+K › Continuity pass): list what changed after a rewrite, what it was and what it is now (a level, a distance, a name). Unwip counts every place the old version appears, then takes you to each one in turn: Change it (Enter), Leave it (Tab), Change all here, or Next chapter. Leave "It's now" empty for changes that need rewriting by hand and it still takes you to each place. The list is kept with the book, and you can start from any chapter.
- LitRPG and GameLit tools (Settings › LitRPG and text shortcuts): brackets close themselves ([ ] and { }), [system messages] show as boxes while you write (the book keeps plain brackets, the way LitRPG is published), and text shortcuts: ;lvl, ;skill, ;quest, ;item, ;status and more, or make your own for any genre.
- Magic systems: a new "The picture" section with a preview (tap it to see it bigger), five styles (Parchment, Clean, Night, Arcane, Blood), three borders, and what to show (summary, costs, kinds of magic, number of spells). Copy picture, Save PNG and Add to book use it.
