- No hard feelings: a book imported from Scrivener can go back out exactly as Scrivener had it. The same folders, order, names and icons (including Scrivener's own picture icons and emoji Unwip can't show) come back. Chapters you added in Unwip go next to the one before them, and things you put in Unwip's Trash go to Scrivener's Trash. It's ticked in the No hard feelings window. This only works for books imported from now on, because Unwip has to note the layout when the book comes in.
