- Settings now follow you between devices through Dropbox: themes and colours, typewriter and animation settings, LitRPG tools and text shortcuts, the default manuscript style, author name, daily goal, quotes, your own templates, favourite fonts, Spark tracking, and which books record a replay. Change one on the PC and the phone has it after its next sync, and the other way round.
- If two devices change settings at about the same time, each setting keeps its newest change, so changing the theme on one and the shortcuts on the other keeps both.
- Things that belong to one device stay put: screen size, window places, library and backup folders, sign-ins, read-aloud voices, spellcheck and automatic updates.
- Sigils: a Smoothing slider for the Pen (like the streamline setting in drawing apps). The pen trails your hand a little and the finished line is rounded off, so wobbles don't show. 0 is off, 10 is smoothest.
- Sigils: faint marks show where each copy of a dot or line will land before you click. A dot goes down when you let go, so you can slide it into place. Dots are bigger and grow with the Line setting. "Snap to guides" clicks points onto the centre, the slice lines and the guide circles (untick to place freely).
- Sigils: a System background (game interface): glowing lines, a ring of ticks, corner brackets and a readout. The words around the edge now work without a rune alphabet, in plain letters (monospace in System).
- Rune alphabets: a "System window" background frames the writing and the alphabet chart like a game's interface.
- Magic systems: a System picture style drawn like a status window. Each spell has a ◆ Window button that shows it as a game's skill window (rank, school, cost bars), with Copy text giving the [bracketed] lines LitRPG books use. In the System style, Add to book puts spells in as [bracketed] system messages.
- Insignia: seven new frames (octagon, tech shield, triangle, split hexagon, circuit ring, gear, HUD brackets), background patterns (grid, hex grid, circuit, scanlines, dot matrix, rays, node network, rings), extras (glow, nodes on the frame, side readouts, barcode, glitch, orbit ring, crosshair, rank chevrons), a symbol size slider, twelve new symbols (network, neural, lock, shield, hex core, radar, power, cursor, level up, target lock, data glyph) and five colour schemes (System, Terminal, Synthwave, Hazard, Void).
- E-books: a chapter with no title of its own showed its number twice on Kindle ("Chapter One" and again underneath). The number line is now the heading, shown once.
- The tour is updated. It now covers Build in the book's toolbar, then carries on to the main screen for Your books, Play, Build and Dropbox sync (Back takes you to the book again). Settings › Help, or "Take a tour" on the main screen, runs it.
- The example book's "Start here" note suggests trying Build: a map of the road to the Borgo Pass, or a rune alphabet.
- Maps: Grid is now a list: No grid, Hex grid or Square grid. Town maps used to draw both at once. Dungeon floors keep their own square grid switch.
- Rune alphabets: the System window background looks like a game interface while you draw too (grid lines, cyan frame, corner brackets, stronger glow). The plain dark panel is now a quiet charcoal, so the two are easy to tell apart.
- Rune alphabets: Slant snaps to upright near the middle and shows its angle; double-click it to reset.
- Insignia: type your own text for the left and right side readouts (left empty, they show a code made from the name).
- Magic systems: in the System style, Border now changes the frame: Double line, Ornate (cut corners, a dashed inner line, ticks) or None.
