## Unwip 0.17.2

- **Chapter titles** now works for chapters made of scenes (folders): *Document names*, *First line* and *Don’t add titles* all change the book. With titles off, each chapter still starts on a new page (and a new section in e-books)
- **Chapter title look:** the font list starts with the same publishing favourites as the main font list, and a **★ button** saves any font to *Your favourites*. Favourites appear at the top of every font list
- In agent submission format the title look is dimmed, with a note saying why (agents expect plain Times New Roman 12)
