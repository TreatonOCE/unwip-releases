- Font for the whole book: change the font of everything in a book at once (chapters, character and place sheets, notes, template entries, titles and headings, and if you like synopses, index cards and split view). It can also clear the fonts and sizes that came in with pasted or imported text, so nothing is left in the old font. Use it for one book, make it the default for new books, or apply it to every book you have. Undo puts the book back. Find it in Manuscript style, Settings, or Ctrl+K › Font for the whole book.
- Split view's document list now works like the binder: folders open and close, and you can type to find a document.
