- Maps: dungeon floors. Pick "Dungeon floor" for a new map or a new section: drag out rooms, carve corridors (narrow or wide), fill back to rock, and drop in stairs, doors, secret doors, chests, traps, a boss, an altar, pillars, a pool or bones. 🎲 Random floor rolls rooms joined by corridors with an entrance, stairs down, a boss room, loot, traps, doors and room numbers (fixed rules and random numbers, no AI). Each floor is its own section, so a whole dungeon sits in one map.
- Maps: a Holo map style, like a game's map screen: dark glass, glowing lines, a grid and plain lettering. Works on world, town and dungeon maps.
- Maps: markers for LitRPG and game maps (waypoint, quest, dungeon, safe zone, boss, shop, respawn), on every kind of map.
- Maps: fog of war. Cover what hasn't been explored yet and reveal it again as the story goes, with a brush, or Cover all / Clear all fog, and a switch to show or hide it.
- Build › Insignia: emblems for corporations, gangs, units and guilds. A hard frame (hexagon, chevron, roundel, badge, diamond, notched ring), one of 28 simple line symbols, flat colour sets (Neon, Corporate, Military, Toxic, Blood, Chrome, Ice) or your own, and a name, designation and code underneath. 🎲 Random rolls a combination to start from.
- Build › Rune alphabets: "System (circuit traces)" ends, where strokes run like traces on a circuit board with a ring where each one ends, and a dark panel background that glows.
- Themes for LitRPG and sci-fi: System (deep blue), Terminal (green on black), Neon (dark with a pink accent) and Status (a light, cool blue). The page gets a thin edge of light; nothing flashy.
- Typing: three new letter effects (Decode, Scan in, Glitch), two new cursors (Underscore, like a command prompt, and Glow) and a quiet "Interface blip" key sound.
- Name ideas (no AI): on every character sheet (🎲 Name ideas…), in Build › Character sheet, and in Ctrl+K. Pick a style (old-world fantasy, invented fantasy, sci-fi, contemporary/LitRPG), lean feminine or masculine or neither, add a middle name or a LitRPG player handle, roll each part on its own, and see the whole name at the bottom. "Use this name" puts it on the sheet.
- Character, place and item sheets: "Edit … fields" now has starting points for Fantasy, Sci-fi, LitRPG and Contemporary stories.
- Random map names now sound like real places (Craneby, Rossingford) instead of stock fantasy names, and a few examples in the app were changed for the same reason.
- LitRPG ledger (Revise panel or Ctrl+K, with LitRPG tools on): reads every [system message] in the book and follows each stat chapter by chapter, with a small graph each. It flags stats that go down with nothing to explain it, or up with no level-up or [+2 Strength] in between, and levels that skip. It also lists every skill, spell, item, title, class and quest with the chapter it first appears in (quests show when they're complete), and notes anything mentioned before it's acquired. Click any of it to jump there.
- Build › Character sheet: a LitRPG status screen. Stats and bars (HP, MP…) with how much they grow each level, an XP curve (Steady, Climbing or Steep) with a level-by-level table, and a status screen at any level in four styles. Copy it into the book as [bracketed] lines the ledger can follow.
- E-books: an option (Settings › LitRPG tools) to make [system messages] real boxes in EPUB and Kindle. Word and print keep plain brackets.
- Continuity pass (Revise panel, or Ctrl+K › Continuity pass): list what changed after a rewrite, what it was and what it is now (a level, a distance, a name). Unwip counts every place the old version appears, then takes you to each one in turn: Change it (Enter), Leave it (Tab), Change all here, or Next chapter. Leave "It's now" empty for changes that need rewriting by hand and it still takes you to each place. The list is kept with the book, and you can start from any chapter.
- LitRPG and GameLit tools (Settings › LitRPG and text shortcuts): brackets close themselves ([ ] and { }), [system messages] show as boxes while you write (the book keeps plain brackets, the way LitRPG is published), and text shortcuts: ;lvl, ;skill, ;quest, ;item, ;status and more, or make your own for any genre.
- Magic systems: a new "The picture" section with a preview (tap it to see it bigger), five styles (Parchment, Clean, Night, Arcane, Blood), three borders, and what to show (summary, costs, kinds of magic, number of spells). Copy picture, Save PNG and Add to book use it.
