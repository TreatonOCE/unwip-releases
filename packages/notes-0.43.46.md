Syncing on iPhone and iPad:
- No more "Dropbox busy, waiting…". Dropbox only lets an account save one file at a time, and the faster sync from the last update was sending several at once, so Dropbox kept asking it to wait. Files now go up one after another (downloads still come down several at a time).
- "Changed elsewhere" only shows when another device really has changed something. It no longer shows for files that came back from Dropbox unchanged, or for leftover bits of a book deleted on the PC.
- Leftover files of a deleted book (when the PC's Dropbox hadn't finished removing it) are no longer fetched back onto your phone or iPad.
- If Dropbox refuses a file (a system file like Thumbs.db that came in with an import), sync skips it instead of trying again and again.
